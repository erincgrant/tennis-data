# tennis-data
# Tennis and Climate: Interactive Data Visualization

**Status:** In progress

## Overview

This project explores the relationship between climate conditions and professional tennis using historical temperature and precipitation data from Climate Central. The goal is to develop an interactive application that helps users explore climate patterns across tennis's major tournaments and different years.

## Tools and Technologies

- Python
- pandas and openpyxl for data processing
- Plotly for interactive visualizations
- Streamlit for the web application

## Current Features

- Interactive exploration of historical tennis-related climate data
- Filters for tournament and year
- Visualizations of temperature and precipitation patterns

## Planned Improvements

- Further refine interactive controls and data visualizations
- Improve the presentation and usability of the application
- Expand the analysis and interpretation of climate patterns

## Project Status

This project is actively under development. Features and visualizations may change as the analysis evolves.
